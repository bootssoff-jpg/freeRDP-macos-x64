# Иконка RDP Mac

Утверждённый пользователем вариант: [rdpmac-icon-arrows-v2.png](rdpmac-icon-arrows-v2.png).
Две встречные синие и бирюзовые стрелки обозначают обмен между компьютерами.
Изображение создано через ImageGen; промпт сохранён в
[rdpmac-icon-arrows-v2.prompt.txt](rdpmac-icon-arrows-v2.prompt.txt).
[rdpmac-icon-1024.png](rdpmac-icon-1024.png) — мастер 1024×1024, полученный
уменьшением исходника без растягивания.

Векторный редактируемый вариант: [rdpmac-icon-arrows-v2.svg](rdpmac-icon-arrows-v2.svg).
Он повторяет мотив двух окон и встречных стрелок и предназначен для правок,
масштабирования и печатных материалов. Для сохранения утверждённой растровой
версии релизный `.icns` собирается из PNG, а не из SVG.

## Почему не логотип FreeRDP

Официальные файлы FreeRDP действительно лежат в репозитории проекта:
`resources/FreeRDP_Icon.svg`, `FreeRDP.ico`, `FreeRDP_Icon.png`
(<https://github.com/FreeRDP/FreeRDP/tree/master/resources>). Исходный код
FreeRDP распространяется по Apache-2.0, но §6 этой лицензии прямо исключает
права на товарные знаки, логотипы и названия: лицензия не даёт разрешения
использовать их как бренд стороннего продукта. Отдельной лицензии или
trademark policy для графики на сайте и в репозитории не опубликовано.

Поэтому логотип FreeRDP **не используется** в иконке, README и названии
приложения. В README есть только текстовая ссылка на проект и честное
указание, что RDP Mac построен на FreeRDP. Если правообладатель выдаст
письменное разрешение, иконку можно заменить отдельным решением; по умолчанию
действует оригинальная утверждённая графика.

## Сборка

```bash
swift scripts/make_icon.swift
```

Скрипт создаёт `Resources/icon.iconset`, `Resources/RDPMac.icns` и
`Resources/Branding/rdpmac-icon-1024.png` из утверждённого PNG. Он не
возвращает старый рисунок монитора с буфером обмена и не растягивает растр.

`rdpmac-icon-concept-v1.png` — предыдущий, не выбранный вариант с молнией.
