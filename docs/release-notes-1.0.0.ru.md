# RDP Mac 1.0.0 — черновик релиза

**Статус:** подготовлен, не опубликован. Локальный артефакт по умолчанию
**unsigned/ad-hoc** и не нотаризован. Меняйте эту строку только после реальной
подписи Developer ID и нотаризации.

RDP Mac — нативный клиент RDP для Intel macOS с надёжным двусторонним текстовым
буфером обмена. Построен на FreeRDP 3.32.2; интерфейс AppKit собственный. Код и
runtime Microsoft Remote Desktop не используются.

## Главное

- Интерфейс EN/RU: язык системы или явный выбор с применением после перезапуска.
- Сворачиваемые группы, редактирование профиля из менеджера, упрощённая форма.
- Восстановление буфера через явное переподключение; остановка фонового опроса и пакетное обновление журнала.

- Независимые сессии в отдельных окнах: `⌘N` — новая, `⌘0` — общий менеджер
  подключений.
- Группы профилей, поиск, открытие нескольких выбранных профилей и реальный
  счётчик сессий.
- Синхронизация буфера только для передней сессии; запоздалые ответы
  отбрасываются, запросы CLIPRDR выполняются последовательно.
- Безопасное копирование кадра с проверкой capacity при изменении размера.
- Явное решение по сертификату; автопринятие невозможно.
- Режим совместимости TLS (`SECLEVEL=0`) только по явному действию и с
  обязательным подтверждением сертификата.
- OpenSSL 3.6.4 собирается из исходника под macOS 12.0 вместо несовместимого
  Homebrew-bottle.
- Оригинальная иконка и векторный исходник; логотип FreeRDP не используется,
  потому что Apache-2.0 §6 не даёт прав на товарные знаки/логотипы.

## Требования

- macOS 12+ на Intel x86_64.
- Homebrew не нужен в runtime: OpenSSL встроен.
- Для неподписанной сборки Gatekeeper потребует ручного подтверждения.

## Известные ограничения

- Только текст: без файлов, изображений, звука, камеры, смарт-карт, IME,
  RD Gateway, RemoteApp/RAIL, мультимонитора и автопереподключения.
- Реальная сессия Windows и ручной чек-лист из `docs/testing.md` в среде
  сборки недоступны. Не утверждайте, что они пройдены, без фактической проверки.
- Нативной arm64-сборки нет.

## Установка

1. Скачайте ZIP или DMG.
2. Переместите `RDP Mac.app` в `/Applications` (в DMG есть ярлык).
3. Поскольку сборка по умолчанию unsigned, разрешите её в
   «Системные настройки → Конфиденциальность и безопасность» либо используйте
   подписанную/нотаризованную сборку.
4. Откройте менеджер подключений, создайте и сохраните профиль.

## Проверка

```bash
shasum -a 256 -c SHA256SUMS
otool -L "RDP Mac.app/Contents/MacOS/RDPMac"
"RDP Mac.app/Contents/MacOS/RDPMac" --selftest
```

SHA-256 ниже относятся к подготовленной unsigned-сборке и совпадают с
`build/dist/SHA256SUMS`. После пересборки значения изменятся; публикуйте только
хеши финальных артефактов.

```text
bf738b5ff06e81a473701a0721c5456b42b7997ac7359aa56a9cbf741b977598  RDP-Mac-1.0.0-x86_64-unsigned.zip
a1eb5ffb0170b25349f0d1577aab8a1741969cc852a0ba51903a69a31088bde8  RDP-Mac-1.0.0-x86_64-unsigned.dmg
```
