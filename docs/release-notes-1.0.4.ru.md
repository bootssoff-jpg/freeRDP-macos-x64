# RDP Mac 1.0.4

Автор: **NFreeZr**.

Релиз про сохранённые подключения: их дублирование, общую учётную запись для
нескольких серверов, выбор размера рабочего стола, работу на медленном канале и
рабочий стол на всё окно.

## Дублирование подключения

Контекстное меню менеджера, кнопка «Дублировать» и `⌘⇧D` открывают редактор с
несохранённой копией: новая запись, тот же сервер, группа, разрешение, качество и
учётная запись. Если изменить только адрес, сохранённый пароль продолжает
работать, потому что он принадлежит учётной записи. До нажатия «Сохранить копию»
ничего не записывается: отмена не создаёт ни профиль, ни элемент Keychain, а
исходное подключение остаётся неизменным.

## Справочник учётных записей

«Справочник…» рядом с полем учётной записи хранит только название, логин и домен.
Пароли остаются в Keychain под `credential/<uuid>` и больше не зависят от адреса
сервера, поэтому одну запись можно использовать в нескольких подключениях;
перед изменением или удалением общей записи интерфейс предупреждает. Удаление
записи сохраняет подключения — они просто спросят пароль. Переключение учётной
записи в форме всегда очищает поле пароля.

Профили из 1.0.3 продолжают работать: пароль, уже лежащий в Keychain,
переносится в новую запись при первом открытии, однократно, старый элемент
сохраняется.

## Пресеты разрешения

Для каждого профиля: как в окне, 1024×768, 1280×720, 1600×900, 1920×1080,
2560×1440 или свой размер. Свой размер проверяется по диапазону
640×480 … 4096×2560 и должен быть чётным; форма объясняет отказ, а не подключается
с другим размером молча. За окном следует только режим «Как в окне»;
фиксированный размер масштабирует изображение с сохранением пропорций.
Переключатель Retina учитывает плотность дисплея в режиме «Как в окне» и
запрашивает в Windows масштаб 200 % для фиксированных размеров — сервер может
второе проигнорировать, и форма об этом говорит. Профили из 1.0.3 сохраняют свой
фиксированный размер.

## Качество и медленные соединения

Пресеты профиля **Обычное**, **Медленный интернет** и **Пользовательское**,
передаются один раз в Client Info PDU: обои, темы, анимации, содержимое при
перетаскивании, композиция рабочего стола, сглаживание шрифтов, 16 бит и уровень
сжатия RDP6. Изменение отдельного флага переводит пресет в «Пользовательское».
«Медленный интернет» отключает обои, темы и сглаживание шрифтов, начинает с
1280×720 без Retina (это видно в списке разрешений) и реже отправляет запросы
изменения размера. Windows вправе игнорировать клиентские флаги; интерфейс не
обещает измеренного ускорения.

## Скрытие панели сеанса

«Вид → Показывать панель сеанса» (`⌘⇧T`). Рабочий стол занимает освободившееся
место и в режиме «Как в окне» следует за новым размером; полноэкранный режим
всегда скрывает панель, а выбор запоминается для новых окон. При скрытой панели
ошибка видна в заголовке окна: `host:port — ошибка`.

Скачайте ZIP или DMG и замените прежнее приложение в Applications. Требуется
macOS 12+ на Intel x86_64. Сборка имеет подпись ad-hoc и **не нотаризована**;
может потребоваться ручное разрешение Gatekeeper, а разрешение «Локальная сеть»
может быть запрошено заново после замены ad-hoc сборки.

Автотесты прошли на русском и английском языках; упаковка проверяет архитектуру,
зависимости, подпись, self-test и контрольные суммы SHA-256. Ручной чек-лист
Windows из `docs/testing.md` — включая новые пункты по разрешению, качеству и
панели — по-прежнему нужно пройти на реальном сервере: живого сеанса в среде
разработки для этого релиза не было.

Проверка загруженных файлов: `shasum -a 256 -c SHA256SUMS` в папке загрузки.
Контрольные суммы приложены к релизу отдельным файлом.
